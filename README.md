# Kelana AI

Proyek kelas [MAIN](https://main.alkademi.foundation) (Mastering AI for Nation Building) dari Alkademi membangun AI Travel Planner using Python, Next.js & Amazon Bedrock berfokus pada pengembangan aplikasi berbasis AI secara end-to-end dengan menggabungkan pemrograman Python, pengembangan web modern, dan layanan kecerdasan buatan berbasis cloud. Peserta akan mempelajari bagaimana membangun REST API menggunakan FastAPI, mengintegrasikan Large Language Model (LLM) melalui Amazon Bedrock untuk menghasilkan itinerary perjalanan, mengelola database dan autentikasi pengguna, serta mengembangkan antarmuka aplikasi menggunakan Next.js dan Tailwind CSS. Selain itu, modul ini juga memperkenalkan teknik AI tingkat lanjut seperti prompt engineering, structured output, dan Retrieval-Augmented Generation (RAG) untuk membangun sistem yang mampu memahami dokumen dan memberikan jawaban yang kontekstual.
